# Brandon Nguyen Portfolio

A professional single-page portfolio website for Brandon Nguyen, a first-year bioengineering student at Lehigh University.

## Live site

https://brandonnguyenth.github.io/Portfolio/

## Overview

This portfolio includes:
- About section
- Interests and strengths
- Project highlights
- Experience timeline
- Resume link
- Contact and social links

## Technologies

- HTML
- CSS
- GitHub Pages deployment

## Run locally

From the project folder, start a local web server:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
